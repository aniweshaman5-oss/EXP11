Google Maps Android Application

Aim

To develop an Android application that displays an interactive map using the Google Maps API.

Features

- Display Google Maps
- Show map markers
- Zoom and camera controls
- Different map types
- Traffic layer
- Location navigation

Technologies Used

- Android Studio
- Kotlin
- Jetpack Compose
- Google Maps Compose SDK
- Google Maps API

Requirements

- Android Studio
- Android device/emulator
- Internet connection
- Google Maps API Key

Procedure

1. Create an Android Studio project using Kotlin and Jetpack Compose.
2. Add the Google Maps Compose dependency.
3. Enable Maps SDK for Android in Google Cloud Console.
4. Generate a Google Maps API key.
5. Add the API key to "AndroidManifest.xml".
6. Implement the map using Google Maps Compose.
7. Add markers and map controls.
8. Run the application on an Android device or emulator.

Result

The Android application successfully displays an interactive Google Map with markers and map controls.
